# 📈 Indian Stock Market Analytics — Nifty Midcap 400

An end-to-end data analytics project that uses **Python-based web scraping, data preparation, and Power BI** to analyze the Indian stock market using data collected from the **Moneycontrol website**.

The project focuses on understanding market sentiment, stock volatility, price momentum, demand-supply behavior, top gainers and losers, and profit/loss contribution across stocks.

---

## 📌 Project Overview

The **Indian Stock Market Analytics Dashboard** transforms raw stock-market data into interactive business intelligence dashboards.

The project follows an end-to-end analytics workflow:

**Web Scraping → Data Cleaning → Data Preparation → Power BI → Market Analysis → Business Insights**

The analysis is based on stocks from the **Nifty Midcap 400** market segment.

---

## 🎯 Project Objective

The primary objectives of this project are:

- Collect stock-market data using Python-based web scraping
- Extract current stock prices, volumes, and buy-sell quantities
- Clean and prepare the scraped data for analysis
- Build interactive Power BI dashboards
- Analyze overall market sentiment
- Identify high and low volatility stocks
- Identify top gainers and losers
- Detect potential breakout candidates
- Analyze demand-supply gaps
- Analyze profit and loss contribution
- Generate actionable market insights

---

| Technology | Purpose |
